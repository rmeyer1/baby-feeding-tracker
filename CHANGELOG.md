# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-22

### Added
- Initial release of Baby Feeding Tracker Bot
- Log feedings by sending a number (1-12 ounces)
- Commands: /start, /help, /today, /week, /month, /last, /parents
- Automatic parent tracking via Telegram user ID
- SQLite database for local data storage
- Parent stats breakdown showing feeding distribution
- Time-ago display for last feeding
